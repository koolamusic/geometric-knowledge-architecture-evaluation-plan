# Preregistered evaluation plan

This repository registers the evaluation plan of the position paper "Toward a Geometric and Compositional Knowledge Architecture for Organizational Knowledge" before any evaluation data exists.

- Registered: 2026-10-15
- File: evaluation-plan.md (Section 10 of the paper)
- SHA-256 of evaluation-plan.md: 13dce441529b6af09078c9b50de1cbcd653399aaa6186734b1faf63ee911829a

The plan fixes, in advance, each component's baseline, metric, test set construction, success threshold, sample size, stopping rule and drop condition. Any later deviation from it will be reported as a deviation, with this commit as the reference point. Nothing in the plan has been run.

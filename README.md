# Preregistered evaluation plan

This repository registers the evaluation plan of the position paper "Toward a Compositional Knowledge Architecture for Organizational Knowledge" by Andrew Miracle, Phyl Georgiou, Christine Okoth and Ese Monday, before any evaluation data exists.

- Registered plan: tag registered-plan, 2026-10-20
- File: evaluation-plan.md (Section 10 of the paper)
- SHA-256 of evaluation-plan.md: 413b34d57539da0a8971a86c18a2abf533d9493d4dddf997c60e78e5358278ab
- Earlier drafts of the plan remain in this repository's history; AMENDMENTS.md summarizes how they changed. All were made before any evaluation data existed.

The plan fixes, in advance, each component's baseline, metric, test set construction, success threshold, sample size, stopping rule and drop condition. It does not change once held-out data has been scored; any later deviation will be reported against tag registered-plan. Nothing in the plan has been run.

# Preregistered evaluation plan

This repository registers the evaluation plan of the position paper "Toward a Geometric and Compositional Knowledge Architecture for Organizational Knowledge" before any evaluation data exists.

- Version 1: 2026-10-15, commit 67777473ef20d2efea180a50886537f17768fb2f
- Version 2 (tag plan-v2): 2026-10-15, commit 69d4c7ea968893a75bbc91b6f361778cee1220a3
- Version 3 (current, tag plan-v3): 2026-10-15, still before any data exists. Changes from each earlier version are listed in AMENDMENTS.md; each adds or tightens, none relaxes.
- File: evaluation-plan.md (Section 10 of the paper; the paper's Section 10 adds one sentence pointing to this registration)
- SHA-256 of evaluation-plan.md (version 3): 1f22704380cd6008d5e7c081a99caa39777ed71cf2a75f1d374a35ac671ebe7e

The plan fixes, in advance, each component's baseline, metric, test set construction, success threshold, sample size, stopping rule and drop condition. It does not change once held-out data has been scored; any later deviation will be reported as a deviation against tag plan-v3. Nothing in the plan has been run.

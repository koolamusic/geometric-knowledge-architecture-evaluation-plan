# Preregistered evaluation plan

This repository registers the evaluation plan of the position paper "Toward a Geometric and Compositional Knowledge Architecture for Organizational Knowledge" before any evaluation data exists.

- Version 1 registered: 2026-10-15, commit 67777473ef20d2efea180a50886537f17768fb2f
- Version 2 (current, tag plan-v2): 2026-10-15, still before any data exists. Changes are listed in AMENDMENTS.md; each adds or tightens, none relaxes.
- File: evaluation-plan.md (Section 10 of the paper; the paper's Section 10 adds one sentence pointing to this registration)
- SHA-256 of evaluation-plan.md (version 2): 15d00f2b53135aef6d98d51692a64c4858492d001c4ea84d86c879cb6180c137

The plan fixes, in advance, each component's baseline, metric, test set construction, success threshold, sample size, stopping rule and drop condition. It does not change once held-out data has been scored; any later deviation will be reported as a deviation against tag plan-v2. Nothing in the plan has been run.

# Preregistered evaluation plan

This repository registers the evaluation plan of the position paper "Toward a Geometric and Compositional Knowledge Architecture for Organizational Knowledge" before any evaluation data exists.

- Version 1: 2026-10-15, commit 67777473ef20d2efea180a50886537f17768fb2f
- Version 2 (tag plan-v2): 2026-10-15, commit 69d4c7ea968893a75bbc91b6f361778cee1220a3
- Version 3 (tag plan-v3): 2026-10-15, commit c3a91c40b248e62c6b41abb0fe4febd3406f3048
- Version 4 (current, tag plan-v4): 2026-10-16, still before any data exists. Changes from each earlier version are listed in AMENDMENTS.md; each adds or tightens, none relaxes.
- File: evaluation-plan.md (Section 10 of the paper; the paper's Section 10 adds one sentence pointing to this registration)
- SHA-256 of evaluation-plan.md (version 4): 98675bbce2bf2f47d06146aab71e45a86d4278a224a81232ddf2adb068ce2ccf

The plan fixes, in advance, each component's baseline, metric, test set construction, success threshold, sample size, stopping rule and drop condition. It does not change once held-out data has been scored; any later deviation will be reported as a deviation against tag plan-v4. Nothing in the plan has been run.
